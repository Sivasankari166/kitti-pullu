# Changelog

All notable changes to this project will be documented in this file.

## v1.0 - Initial Release
- First working version of the Gilli Danda game.
- Added three modes: Solo Practice, Vs Computer, Pass & Play.
- Basic scoring and level system added.

## v1.1
- Refreshed the mustard accent color to a slightly warmer shade.
- Added a 7th tip on the How to Play screen about using the Space bar.

## v1.2
- Added a confetti animation that plays when you beat your personal best distance in Solo Practice.

## v1.3
- Added a "Reset High Score" button on the main menu, with a confirmation prompt before resetting.

## v1.4
- Added a pulsing glow animation to the Play button to draw attention to it.

## v1.5
- Added a small version tag (v1.5) in the corner of the main menu.
