# Kitti Pullu (Gilli Danda)

A simple browser-based version of the traditional Tamil street game **Gilli Danda** (கிட்டிப்புள்ளு), built using HTML, CSS, and JavaScript.

## How to Play

- Tap/click to flip the gilli (small stick) into the air.
- Tap/click again while it's in the air to strike it as far as possible.
- Distance struck decides your score.
- You can also use the Space bar instead of tapping.

## Game Modes

- **Solo Practice** — Chase your best distance and level up.
- **Vs Computer** — 3 hits each, best distance wins.
- **Pass & Play** — Take turns with a friend on one device.

## How to Run

Just open `index.html` in any web browser. No installation needed.
